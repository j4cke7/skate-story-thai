ม็อดภาษาไทยสำหรับ Skate Story
สำหรับเกมเวอร์ชัน Steam บน Windows build 21628663

ม็อดนี้เพิ่มภาษาไทยเป็นภาษาใหม่ในเกม ภาษาเดิมของเกมทุกภาษายังเลือกได้ตามปกติ
แปลข้อความในตารางภาษาหลักของเกมครบ 2,304 รายการ
ข้อความบางส่วนที่อยู่นอกตารางนี้อาจยังเป็นภาษาอังกฤษ
ฟอนต์ภาษาไทยรวมอยู่ในม็อดแล้ว ไม่ต้องติดตั้งฟอนต์เพิ่ม

วิธีติดตั้ง
1. ปิดเกมให้เรียบร้อย
2. แตกไฟล์ ZIP ทั้งหมดไว้ในโฟลเดอร์เดียวกัน เช่น โฟลเดอร์บน Desktop
   แตกไว้ที่ไหนก็ได้ ไม่จำเป็นต้องใส่ในโฟลเดอร์เกม
   อย่าแยกหรือลบไฟล์ที่อยู่ในชุดม็อด
3. ดับเบิลคลิก Install.cmd แล้วรอให้ติดตั้งเสร็จ
   ตัวติดตั้งจะค้นหาโฟลเดอร์เกมและสำรองไฟล์เดิมให้อัตโนมัติ
4. เปิดเกม ไปที่ Settings แล้วเลือกภาษา ภาษาไทย

วิธีถอนม็อด
1. ปิดเกม
2. ดับเบิลคลิก Uninstall.cmd ในโฟลเดอร์ม็อด
3. เปิดเกมอีกครั้ง แล้วเลือกภาษาที่ต้องการใน Settings

เก็บโฟลเดอร์ม็อดไว้หากต้องการใช้ Uninstall.cmd ในภายหลัง
อย่าลบไฟล์สำรอง .skate-thai-original-21628663.bak ที่ตัวติดตั้งสร้างไว้ในโฟลเดอร์ SkateStory_Data
Status.cmd ใช้ดูว่าตอนนี้ติดตั้งม็อดอยู่หรือไม่

หากติดตั้งไม่สำเร็จ
- ตรวจว่าแตกไฟล์ ZIP ครบแล้ว และปิดเกมอยู่
- หากติดตั้งถูกขัดจังหวะ ให้ปิดเกมแล้วเรียก Install.cmd อีกครั้ง
- หากขึ้นคำเตือนว่าเวอร์ชันเกมไม่ตรง ตัวติดตั้งจะติดตั้งต่อเมื่อไฟล์ที่ม็อดแก้ยังตรงกับต้นฉบับ
  หากข้อความแสดงผิดปกติ ให้ถอนด้วย Uninstall.cmd
- หาก Steam อัปเดตไฟล์ข้อมูลเกมแล้ว ม็อดรุ่นนี้จะติดตั้งไม่ได้ ให้รอม็อดรุ่นใหม่
  Uninstall.cmd ยังใช้ได้ และจะลบเฉพาะไฟล์สำรองของม็อด ไม่แตะไฟล์เกมรุ่นใหม่
- หากแจ้งว่าไฟล์เกมถูกแก้ไขหรือเสียหาย ให้คืนไฟล์เกมต้นฉบับก่อนติดตั้ง
  คุณตรวจสอบไฟล์เกมได้ใน Steam โดยคลิกขวาที่เกม > Properties > Installed Files
  > Verify integrity of game files การตรวจนี้อาจนำไฟล์ที่ม็อดอื่นแก้ไว้กลับเป็นต้นฉบับด้วย

หากตัวติดตั้งหาโฟลเดอร์เกมไม่พบ
ทำส่วนนี้เฉพาะเมื่อ Install.cmd แจ้งว่าหาเกมไม่พบ
1. ใน Steam คลิกขวาที่ Skate Story แล้วเลือก Manage > Browse local files
2. คัดลอกพาธจากแถบที่อยู่ของหน้าต่างโฟลเดอร์ที่เปิดขึ้น
3. กลับไปที่โฟลเดอร์ม็อด คลิกแถบที่อยู่ พิมพ์ powershell แล้วกด Enter
4. วางคำสั่งด้านล่าง โดยเปลี่ยนพาธในเครื่องหมายคำพูดเป็นพาธเกมที่คัดลอกมา แล้วกด Enter

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Patch.ps1 -Action Install -GameRoot "D:\SteamLibrary\steamapps\common\Skate Story"

สิ่งที่ม็อดแก้
ม็อดแก้เฉพาะไฟล์ SkateStory_Data\resources.assets โดยสร้างจากไฟล์ต้นฉบับในเครื่องคุณ
ชุดม็อดไม่มีไฟล์เกมต้นฉบับหรือ DLL และไม่ต้องติดตั้ง Python หรือโปรแกรมอื่นเพิ่ม
ใช้ Windows PowerShell 5.1 ขึ้นไป ซึ่งมีอยู่ใน Windows อยู่แล้ว
